# COS PRO 파이썬 실습 웹앱

브라우저 안에서 파이썬을 실행하고(Pyodide), 정답 코드의 출력과 비교해 자동 채점하는 실습 사이트입니다.
서버가 필요 없고, 채점 결과는 화면에만 보이며 어디에도 보내지 않습니다.

## 화면 구성
- **왼쪽 목차**: 문제 목록. 위쪽 바 왼쪽 끝의 버튼으로 접고 펼 수 있습니다(넓은 화면에서는 접은 상태를 기억). 누르면 그 문제로 이동하고, 정답/오답 표시가 붙습니다.
- **가운데**: 문제가 위에서 아래로 이어집니다. 문제마다 `지문 → 코드 입력 → [코드 실행] [채점하기] → 실행 결과/채점 결과`.
- **위쪽 바**: 파이썬 준비 상태, 해/달 버튼(라이트·다크 모드, 고른 값은 브라우저에 기억), 학생/관리자 모드 전환(자물쇠 버튼).
- **학생 모드는 10문제씩**: 3급 문제 중 10문제만 보입니다. 1~5번은 언제나 [빈칸], 6~10번은 [구현]이고, 유형마다 기출 바탕 2문제 + 새 유형 3문제를 무작위로 고릅니다(처음 열 때도 무작위). 고른 10문제는 브라우저에 기억됩니다.
  - **[다시 풀기]** : 같은 10문제를 처음부터 (작성한 코드·채점 결과 지움)
  - **[새로 풀기]** : 직전과 겹치지 않는 10문제를 무작위로 새로 고름
  - 학생 모드는 언제나 `public/problems.json` 의 문제를 씁니다. 관리자가 이 브라우저에서 고친 문제는 관리자 모드에서만 보입니다.
  - 관리자 모드에서는 모든 문제가 보입니다.
- **지금은 3급만 운영합니다.** 기본 문제(`public/problems.json`)는 3급 50문제([빈칸] 25 + [구현] 25)입니다.
  - 20문제: 기출 20문제와 비슷한 문제 (숫자·조건·상황을 바꿈, 유형은 기출 그대로)
  - 30문제: 기출과 비슷한 유형·난이도의 다른 문제 (빈칸 15 + 구현 15)
- 지문은 시험 화면처럼 문제 설명 / 입력 설명 / 출력 설명 / 예제(표 + `# 예제` 설명) 순서이고, 예제 2개 외에 채점용 숨은 입력 2개가 더 있습니다.
- **[빈칸] 문제**는 코드가 고정되어 있고, ⬜ 자리마다 한 줄짜리 입력칸이 있습니다(들여쓰기 그대로). 입력칸에 쓴 답을 끼워 넣은 코드로 실행·채점합니다.
- 코드 입력칸(또는 빈칸 입력칸)에서 `Ctrl + Enter` 를 누르면 바로 실행됩니다.

## 설치와 실행 (Windows PowerShell)

Node.js 18 이상이 필요합니다.

```powershell
cd week-01\cospro-lab
npm install        # 필요한 라이브러리 설치 (처음 한 번)
npm run dev        # 개발용 서버 실행 → 화면에 나온 http://localhost:5173 열기
```

설치되는 라이브러리 (`package.json`)

| 라이브러리 | 하는 일 |
|---|---|
| react, react-dom | 화면 만들기 |
| @monaco-editor/react | VS Code 와 같은 코드 에디터 |
| react-markdown, remark-gfm | 문제 지문(마크다운, 표, 이미지) 보여 주기 |
| lucide-react | 아이콘 |
| tailwindcss, @tailwindcss/vite, @tailwindcss/typography | 디자인(CSS) |
| vite, @vitejs/plugin-react | 개발 서버와 빌드 도구 |

Pyodide(브라우저용 파이썬)는 설치하지 않고 인터넷(jsDelivr CDN)에서 불러옵니다. 그래서 **인터넷 연결이 필요**하고, 처음 열 때 몇 초 걸립니다.

## 설정 (.env.local)

`.env.example` 을 복사해 `.env.local` 을 만들고 값을 채웁니다. `.env.local` 은 GitHub 에 올라가지 않습니다.

```powershell
Copy-Item .env.example .env.local
```

- `VITE_ADMIN_PASSWORD_HASH` : 관리자 비밀번호의 **해시값**. 비워 두면 처음 관리자 모드에 들어갈 때 그 브라우저에서 새로 만듭니다.
  ```powershell
  node -e "console.log(require('crypto').createHash('sha256').update('내비밀번호').digest('hex'))"
  ```

`.env.local` 을 바꾼 뒤에는 `npm run dev` 를 껐다가 다시 켜야 반영됩니다.

## 문제 만들기 (관리자 모드)
1. 위쪽 자물쇠 버튼 → 비밀번호 입력.
2. 문제마다 제목, 지문(마크다운), 시작 코드, **모범 정답 코드**, (필요하면) 표준 입력을 넣고 [저장].
   - **[마크다운 붙여넣기]** : 다른 곳에서 쓴 마크다운 지문을 붙여 넣고 미리 본 뒤, 지문 끝에 붙이거나 지문을 통째로 바꿉니다.
   - **[이미지]** 또는 지문 칸에서 `Ctrl+V` : 이미지를 넣습니다. 큰 이미지는 가로 1000px 로 줄여서 저장합니다.
   - **[표 추가]** : 행·열 수를 정하고 칸마다 내용을 입력하면 마크다운 표가 커서 자리에 들어갑니다(첫 줄은 제목 줄).
   - [정답 코드 실행해 보기]로 정답 코드가 제대로 출력하는지 꼭 확인하세요.
3. **[자동 생성]** : 범위(조건문 · 반복문 · 리스트 · 문자열 · 내장함수), 유형([빈칸] · [구현]), 문제 수를 고르면
   미리 만들어 둔 문제 틀(3급 50개 `src/lib/generator3.js` — 기출 바탕 20개 + 새 유형 30개, 틀마다 유형이 정해져 있음)에 숫자·조건·테스트 값을 무작위로 바꿔 넣어 문제를 만듭니다. 지문, 예시 표, 시작 코드, 정답 코드가 함께 만들어집니다.
4. 고친 내용은 **그 브라우저에만** 저장됩니다. 학생들에게 배포하려면 [내보내기]로 받은 `problems.json` 을 `public/problems.json` 에 덮어쓰세요.

   - `input()` 으로 입력을 받고 `print` 로 출력하는 3급 형식입니다. 입력 세트는 예제 2개 + 숨은 입력 2개입니다.
   - 2급 문제 틀(`solution` 함수 형식, `src/lib/generator.js`)은 코드에 남아 있지만 지금 화면에서는 쓰지 않습니다.

## 채점 방식
학생 코드와 정답 코드를 같은 입력으로 실행해 **print 로 나온 출력 전체**를 비교합니다.
표준 입력 칸에 `---` 만 있는 줄을 넣으면 입력 세트가 여러 개로 나뉘고, **모든 입력 세트에서 출력이 같아야** 정답입니다.
(학생의 [코드 실행]은 첫 번째 입력 세트로만 실행합니다.)

```
7
41 23 27 0 12 36 50
---
5
1 2 3 4 5
```

줄 끝 공백과 마지막 빈 줄 차이는 무시합니다. 그래서 문제의 시작 코드 아래에 `print(solution(...))` 같은 테스트 코드를 넣어 두는 것이 좋습니다.
실행이 10초를 넘으면(무한 반복 등) 자동으로 멈춥니다.
