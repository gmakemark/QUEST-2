# COS PRO 3급 파이썬 대비반 (수업용 웹앱)

파이썬이 처음인 코딩 강사를 위한 COS PRO 3급 대비 수업 사이트입니다. 2시간씩 3회(STEP1~3) 수업에 맞춰 이론 설명, 연습, 실습, 실전 문제를 담았습니다.
서버 없이 브라우저 안에서 파이썬을 실행합니다(Pyodide). STEP 공개/비공개와 계정·작업 저장은 Netlify 서버 함수가 맡습니다.

## 수업 구성

| STEP | 내용 |
|---|---|
| STEP1 | print(), 변수, 자료형, 연산자, input(), 인덱싱·슬라이싱, 조건문, 반복문(for·range, while) |
| STEP2 | 문자열·리스트 기본 기능, 시퀀스와 반복문, 합계·최댓값·절댓값·배수·문자 판별을 반복문으로 직접 구하기, break·continue, 조건부 표현식 |
| STEP3 | 3급 시험 알아보기, 여러 값 입력(split·map), 내장 함수·검사 메서드, % 서식(소수점 자리수), 별 그리기 패턴, 실전 10문제 |

- **연습**: 개념 하나에 코드 칸 하나. 칸 맨 위 주석이 문제이고 그 아래에 직접 씁니다. [예시 답안]이 있습니다.
- **실습**: 조금 더 긴 구현 문제. [예시 답안]이 있습니다.
- **실전 10문제**(STEP3): 시험 형식(1~5 빈칸, 6~10 구현). 숨은 입력까지 채점하고, 오답 뒤에 [정답 보기]가 열립니다.
- 소수점 자리수는 **% 서식만** 씁니다(`%d`, `%f`, `%.1f`, `%.2f`, `%s`). COS PRO 는 C 언어 출력 결과로 채점하고 `round()` 는 감점되기 때문입니다.

## 화면 기능
- **[실행] / Ctrl+Enter**: 코드 실행. 출력 또는 파이썬과 같은 오류 메시지(Traceback)가 나옵니다.
- **input()**: 실행 결과 창에 입력칸이 나타납니다. 값을 넣고 Enter 를 누르면 이어서 실행됩니다.
  (브라우저 실행기는 중간에 멈출 수 없어서, 입력이 들어올 때마다 지금까지의 입력을 모두 넣어 처음부터 다시 실행합니다)
- **[+ 코드] / [+ 텍스트]**: 블록 사이에 마우스를 올리면 나타납니다. 수강생이 자기 코드 칸이나 메모를 원하는 자리에 넣을 수 있습니다.
- **[로그인]** (배포 사이트에서만): 아이디·비밀번호로 가입하거나 로그인하면 고친 코드, 빈칸 답, +코드·+텍스트 칸이 서버에 저장되어 다른 컴퓨터에서도 이어서 볼 수 있습니다. 바꾼 뒤 1초 뒤에 저장되고, 버튼 옆에 저장됨/저장 중이 나옵니다.
  - 계정마다 따로 저장됩니다. 관리자가 쓴 칸이나 고친 코드도 다른 사람 화면에는 나오지 않습니다.
  - 로그인하지 않으면 예전처럼 그 브라우저에만 저장됩니다(로그인해도 브라우저에 있던 내용이 계정으로 옮겨지지는 않습니다).
- 수업 내용이 바뀌면 예전에 저장한 코드는 버리고 새 내용을 보여 줍니다.
- 라이트/다크 모드, 왼쪽 목차 접기.

## 관리자 모드 (위쪽 [수업 모드] 버튼 → 비밀번호)
- **[STEP1·2·3 공개/비공개]**: 처음 배포하면 STEP1 만 공개, STEP2·3 은 잠겨 있고 버튼으로 엽니다. 모든 수강생에게 바로 적용됩니다(열려 있는 화면은 2분 안에, 또는 새로고침할 때).
- **STEP 을 비공개로 바꾸면 그 STEP 을 정리**합니다(되돌릴 수 없음).
  - 수강생: 그 STEP 의 +코드·+텍스트 칸과 고친 코드·빈칸 답을 지웁니다.
  - 관리자 계정: 그 STEP 의 +코드·+텍스트 칸은 남기고, 고친 코드와 빈칸 답만 지웁니다.
- **STEP1·2·3 이 모두 비공개가 되면** 수강생 아이디·비밀번호(와 남은 작업)도 지웁니다. 관리자 계정은 남습니다. 열려 있던 수강생 화면은 다음 저장 때 로그아웃됩니다.
  - **관리자 계정**은 로그인한 상태로 관리자 모드에 들어간 계정입니다(로그인과 관리자 모드 순서는 상관없음). 처음 한 번만 하면 계속 관리자 계정입니다.
- **[정답 창 열기]**: 새 창에 지금 STEP 의 연습·실습 예시 답안과 실전 문제 정답이 나옵니다. 다른 모니터에 두면 수업 화면에서 주제를 옮길 때 따라 움직입니다.
- 관리자 모드에서는 잠긴 STEP 도 미리 볼 수 있습니다.
- **[수정]**: 연습·실습·코드 칸 위에 있습니다. 문제 주석과 시작 코드, 예시 답안(실습은 제목·문제 설명도)을 고쳐 [저장 · 모두에게 적용] 하면 서버에 저장되어 **모든 수강생의 수업 화면이 한꺼번에 바뀝니다**. 다시 배포하지 않아도 됩니다.
  - 열려 있는 화면은 2분 안에, 또는 새로고침하거나 창으로 돌아올 때 바뀝니다. 정답 창도 함께 바뀝니다.
  - 문제 주석을 고치면 예시 답안 맨 위의 같은 주석도 따라 바뀝니다.
  - 수강생이 그 칸에서 고쳐 둔 코드는 새 내용으로 바뀝니다.
  - 고친 칸에는 [수정됨] 이 붙고, [원래대로] 로 되돌릴 수 있습니다.
  - 설명 글과 STEP3 실전 문제는 고칠 수 없습니다(파일에서 고쳐 다시 배포).
  - 고친 내용은 `src/content` 파일에는 들어가지 않고 서버에만 있습니다. 나중에 파일에서 그 칸을 고치면, 서버에 있던 수정은 그 칸에 더는 적용되지 않습니다.
  - `npm run dev` 에서는 그 브라우저에만 저장됩니다.

## 내 컴퓨터에서 실행 (Windows PowerShell)

Node.js 18 이상이 필요합니다.

```powershell
cd week-01\cospro-class
npm install
npm run dev        # 화면에 나온 주소(예: http://localhost:5173) 열기
```

내 컴퓨터에는 서버 함수가 없으므로 STEP2·3 이 모두 열려 있고, [로그인] 버튼이 없어 작업은 브라우저에만 저장됩니다. 관리자 비밀번호는 처음 들어갈 때 그 브라우저에서 만듭니다(`.env.example` 참고).

## 배포 (Netlify)

1. 이 저장소를 GitHub 에 올립니다(push).
2. Netlify → **Add new site → Import an existing project → GitHub** → 이 저장소 선택.
3. **Base directory**: `week-01/cospro-class` (나머지 빌드 설정은 `netlify.toml` 에서 자동으로 읽습니다)
4. **Environment variables** 에 `ADMIN_PASSWORD` = (관리자 비밀번호). 비밀번호는 여기에만 넣고 어떤 파일에도 적지 않습니다(공개 저장소).
   처음 배포 뒤에 넣었거나 바꿨다면 **Deploys → Trigger deploy** 로 다시 배포해야 적용됩니다.
5. 처음 배포하면 STEP2·3 은 **비공개** 입니다.

이후에는 GitHub 에 push 할 때마다 Netlify 가 자동으로 다시 배포합니다(1~2분).

## 수업 내용 고치기

내용은 `src/content/step1.js`, `step2.js`, `step3.js` 에 있습니다.

```js
md`
  ### 소제목            ← 소제목 하나가 흰 박스 하나
  설명 첫 줄           ← 줄을 바꾸면 화면에서도 줄바꿈
  **강조**, 코드는 \`print()\` 처럼 (백틱 앞에 \)
`,
task(`정수 2026 출력하기`, py`print(2026)`),                                   // 연습 (문제 주석 + 예시 답안)
task(`s 의 첫 글자 출력하기`, py`print(s[0])`, { given: py`s = "PYTHON"` }),   // 미리 넣어 둘 코드
ex({ title: "제목", prompt: md`문제 설명`, answer: py`예시 답안`, sample: "입력 예" }),  // 실습
```

STEP3 실전 10문제는 `src/content/step3-problems.json` 입니다(cospro-lab 의 3급 문제 틀에서 뽑아 만듦).
